CalenderZW support

How can we help?

Get help with timetable links and calendar setup. Email support@aido.co.zw and include the public class link when reporting a timetable problem.

Calendar setup

If a calendar does not appear immediately, check that the selected reminder preset was saved, your device calendar sync is enabled, and your calendar app has network access.

Apple subscriptions

Use the Apple Calendar subscription option from the live HTTPS site where offered. Apple Calendar controls refresh timing, so a published timetable change may not appear immediately on every device.

.ics import guidance

A downloaded .ics file is a one-time import into many calendar apps. Future published timetable changes may require another import unless you use a supported subscription option.

Subscription links

Private subscription URLs should not be posted in class groups or shared publicly. Share the public /t/… timetable link instead.

Google Calendar

Direct CalenderZW Google Calendar connection should only be used when it is explicitly offered as enabled. Otherwise use the supported import or subscription method shown on your timetable page.

Report a timetable problem

Email support@aido.co.zw with the public timetable link, course or session involved, and the correction needed. Also see the Privacy Policy and Data deletion page.
