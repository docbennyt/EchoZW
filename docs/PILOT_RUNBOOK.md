# Pilot Runbook

1. Create the institution and campus.
2. Add faculty, department, programme, cohort, and academic period.
3. Create a draft timetable.
4. Import CSV rows or enter lectures manually.
5. Resolve validation errors row by row.
6. Submit the timetable for verification.
7. Verifier reviews source evidence and publishes.
8. Generate QR poster and share link.
9. Inspect activation and correction metrics.
10. Process correction reports.
11. Publish a new version or rollback when needed.
12. Revoke compromised feed tokens.
13. Help students check calendar notification settings.
